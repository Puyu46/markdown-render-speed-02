A fast, dependency-free Markdown parser written from scratch that renders CommonMark 0.31.2 plus the GFM extensions (tables, task lists, strikethrough, extended autolinks) byte-identically to marked 18.1.3, and faster. `parse.js` exports a single `parse(markdown)` function; `main.ts` reads every case from `/input/cases.json` and writes the HTML array to `/output/html.json`.

## Run it

```sh
node main.ts
```
